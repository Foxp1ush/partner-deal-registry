# 파트너 영업권 관리 v2

> 총판-파트너 영업에서 **"이 고객, 누가 먼저 잡았나"** 분쟁을 없애는 영업권(deal registration) 관리 도구.
> 2026년 재직 중 직접 만들어 운영했던 v1을 회고하고 **새로 설계한 버전**입니다. 모든 데이터는 가상입니다.

## 무엇을 하나
| 기능 | 설명 |
|---|---|
| 고객사 등록 | 명함·사업자등록증 이미지를 올리면 **AI(Claude)가 회사명·사업자번호·담당자를 자동 입력** |
| 선점 판정 | ① 사업자번호 일치 ② 법인 표기를 뺀 회사명 일치 → 등록 차단 / ③ 이름이 비슷하면 AI 의견을 붙여 **관리자 검토**로 |
| 90일 보호 | 등록 시점부터 90일 보호, 만료 14일 전부터 알림, 지나면 자동 만료. 총판 연장은 횟수 제한 없이, 등록별·고객사 누적 연장 횟수를 표시 |
| 계약 고객 | 수주 시 계약 종료일을 입력하면 종료일까지(최대 3년) 보호. 갱신하면 종료일 연장, 종료 60일 전 알림 |
| 이력 로그 | 등록·차단·승인·반려·만료를 모두 기록 → 분쟁 시 근거 |
| 공지 | 정책 공지를 한 곳에서 |
| 영업 관리(CRM) | 고객사별 영업 단계·활동 이력. 재등록(갱신)해도 이력이 이어지고, 기록은 수정·삭제 불가. 이관돼도 이전 파트너의 기록은 새 파트너에게 비공개(보존) |
| 직원 계정 | 파트너 관리자는 회사 전체, 영업 담당자는 자기 담당 고객만. 퇴사 처리 시 로그인 차단 + 담당 고객 인계 |
| 계정 발급 | 회원가입 없음. 총판이 파트너사+관리자 계정 발급 → 파트너 관리자가 직원 계정 발급. 임시 비밀번호는 한 번만 표시, 첫 로그인 때 변경 강제. 계약 종료 시 일괄 차단 |
| 총판 열람 통제 | 총판은 단계별 집계만 보고, 상세는 사유 입력 후 열람 → 해당 파트너에게 열람 기록 공개 |

**설계 원칙**: AI는 판단을 *돕고*, 차단은 규칙이, 애매한 경우의 결정은 사람이 한다.

## 실행
```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
set ANTHROPIC_API_KEY=...        # 없으면 수동 입력 모드로 동작
.venv\Scripts\python.exe -m streamlit run app.py
```
- 처음 실행하면 `data/registry.db`에 가상 데이터를 채운다. 지우면 초기화.
- 로그인 계정(시연용, `seed.py`의 `DEMO_ACCOUNTS`): 파트너 관리자 `partner-a`/`partner-b`/`partner-c`, 영업 담당자 `a-sales1`·`a-sales2` 등 (비밀번호 모두 `demo1234`), 총판 관리자 `admin` (`admin1234`). 실제 운영 전에 반드시 바꾼다.
- 파트너 화면에는 다른 파트너의 이름·고객사명이 보이지 않는다(선점 여부와 보호 만료일만).
- 환경변수: `CLAUDE_MODEL`(기본 `claude-opus-5-5`), `AI_DAILY_LIMIT`(기본 30회/일)

## 배포 (Streamlit Community Cloud)
1. 이 폴더를 본인 GitHub 저장소로 push
2. share.streamlit.io → New app → `app.py` 선택, Advanced settings에서 **Python 3.13** (로컬과 같은 버전)
3. (선택) Settings → Secrets에 `ANTHROPIC_API_KEY = "..."` 입력. 없으면 AI 기능만 꺼지고 나머지는 동작
4. 데모 DB와 증빙 이미지는 앱이 재시작되면 가상 데이터로 초기화된다 (무료 서버는 파일을 보관하지 않음 — 실제 운영은 회사 자체 서버 전제)
5. 패키지 버전은 `requirements.txt`에 모두 고정했다. 특히 `starlette`는 1.x로 올리면 이미지가 깨진다
6. 시연용 명함의 한글은 `assets/fonts/NanumGothic-Regular.ttf`(OFL)로 그린다. 로그인 배경 이미지는 `assets/login_bg.png` (파일을 바꾸면 배경이 바뀐다, 없으면 배경 없이 동작)

## 구조
- `matching.py` — 회사명 정규화, 사업자번호 검증, 중복 판정 (AI 없이 동작)
- `ai_extract.py` — Claude API: 이미지 추출, 유사 회사명 판단
- `db.py` — SQLite (파트너·등록·이력·공지)
- `seed.py` — 가상 데이터 (사업자번호 앞자리 000 = 실존하지 않는 번호)
- `app.py` — Streamlit 화면 (파트너 / 총판 관리자)
- `auth.py` — 로그인 (비밀번호는 해시로만 저장, 퇴사 처리된 계정 차단)
- `accounts.py` — 계정 발급·관리: 파트너사 등록, 관리자·직원 계정, 임시 비밀번호, 역할 지정, 계약 종료
- `crm.py` — 영업 관리: 단계·활동 이력, 보는 범위(담당자/관리자/총판), 직원 퇴사·인계, 총판 집계·사유 열람
- `admin.py` — 총판 관리자 조치 (해제·연장·이관·회사명 수정·반려 되돌리기, 충돌 검사 포함)
- `registry.py` — 등록 판정 흐름을 화면과 분리한 모듈 (실제 운영 대비용, 아직 app.py에 미연결)
